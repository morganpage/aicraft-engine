Lava pool. Zero art assets.

The surface is a sum-of-Gerstner-wave polyline (sharp-crested, flat-troughed — viscous). Fire and smoke are deterministic particle emitters with heterogeneous physics: fire (gravityScale 0.6) arcs up and falls back as embers; smoke (gravityScale −0.4) rises against gravity and billows. Move. Jump. Collide.

A playable platformer built from six library modules: input edges, AABB collision, follow camera, hit-stop freeze, fixed-step loop, and squash-stretch. Zero game engine. Zero dependencies. Just the library.

← → to move · Space to jump · R to reset 

// Six modules compose into a game loop:
const loop = createGameLoop({
  step: (dt) => {
    const input = keyboard.poll();
    const xRes = resolveAxisX(body, vx, solids);
    const yRes = resolveAxisY(body, vy, solids, prevBottom);
    camera = updateCamera(camera, body, level, viewport);
    if (yRes.landed) hitStop = triggerHitStop(hitStop);
  },
  render: () => { ctx.translate(-camera.x, -camera.y); /* draw */ },
});
