Move. Jump. Edit.

A playable platformer built from the library's input, collision, kernel, and FX modules — plus an integrated level editor. Toggle Edit to draw your own platforms with click-drag, place spawns / exits / moving platforms, and drag the cyan waypoint handles to redefine a moving platform's path. Press Play and the kernel runs against your level through a snapshot boundary — Stop restores the editor with full undo history preserved.

← → to move · Space to jump · R to reset · toggle ✎ Edit to modify the level · click-drag to draw platforms · click a moving platform to drag its waypoints 

// Editor + playtest loop compose from public APIs:
const state = createEditorState(level);
let next = applyOp(state, instantiateCatalogEntry(entry, at).op);
// Play: snapshot → compile → run kernel → render
const { snapshot, runtimeLevel } = enterPlaytest(next);
const compiled = compileLevel(runtimeLevel);
let runtime = compiled.initialState;
runtime = stepPlatformer(runtime, input, compiled.staticSolids, dt).state;
// Stop: restore editor from snapshot, history preserved
next = exitPlaytest(next, snapshot);

Spider — procedural legs that anchor to the ground

Each spider is driven by an IK gait solver with switchable coordinated / frantic modes, terrain-adaptive foot placement via tile-grid queries, and a segmented body with breathing oscillation, jittered outlines, and spring-rod pedipalps. Four variants below: two walkers at different scales and speeds, plus two idle palette showcases. All deterministic from fixed seeds.

🕷 toggles gait mode · sliders adjust speed and visible leg count
