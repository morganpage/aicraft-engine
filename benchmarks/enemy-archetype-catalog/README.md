# Enemy Archetype Validation

`charger-prototype.png` is the deterministic Phase 8 review sheet for the
charger candidate. It shows patrol, shape-based windup, locked dash, impact,
recovery, both facings, grayscale telegraphy, and a player scale reference.

Regenerate with:

```bash
npm run benchmark:charger
```

`charger-production.png` is rendered from the production charger module. It is
byte-identical to the approved prototype sheet.
