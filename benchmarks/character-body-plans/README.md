# Character Body-Plan Validation

`humanoid-production.png` is the deterministic validation sheet for the current
production humanoid, rendered from `src/character/humanoid` by
`benchmarks/_scripts/humanoid-validation-render.ts`. As of 0.5.0 it shows the
polished neutral idle and the targeted-arm pose; the gait, airborne, landing,
and ceiling motion poses are wired into the public API but render
idle-equivalent geometry today and are deferred to 0.6.0 (Phases H3/H4) —
panels carrying a "(0.6.0)" suffix reflect that. Regenerate with:

```bash
npm run benchmark:humanoid
```

`humanoid-prototype.png` is the rejected historical candidate from the
prototype phase. Per Decision #9 of
`docs/design/humanoid-visual-revision-plan.md`, it is retained as historical
evidence only: it is no longer regenerated by the benchmark, and production is
NOT asserted or expected to be byte-identical to it. The benchmark retains only
the production render-twice determinism check.

`humanoid-reference-study.png` is an original analytical diagram derived from
the researched platformer strategies in
`docs/research/humanoid-platformer-visual-reference.md`. It contains no copied
game sprites. Regenerate it with:

```bash
npx tsx benchmarks/_scripts/humanoid-reference-study-render.ts
```
